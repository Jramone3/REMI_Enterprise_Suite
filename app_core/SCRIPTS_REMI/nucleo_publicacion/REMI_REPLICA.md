# REMI – Guía de Réplica y Adaptación

Este documento describe cómo replicar REMI en otro entorno, respetando su trazabilidad, estructura modular y propósito patrimonial.

## Requisitos

- Entorno Linux con acceso a terminal
- Carpeta raíz trazada (ej: /mnt/sda7/REMI/)
- Clave GPG propia o derivada
- Registro patrimonial local (`REMI_log_patrimonial.txt`)

## Pasos básicos

1. Clonar o copiar la estructura de REMI
2. Adaptar los manifiestos con nueva identidad
3. Registrar la réplica con fecha y custodio
4. Activar submódulos según necesidad
