# 🌱 REMI – Agente Patrimonial Autónomo

REMI es un agente simbólico y técnico sembrado desde Linux Mint XFCE, diseñado para custodiar, aprender y expandir el legado humano a través de ciclos reproducibles.
![REMI Visual Fase 2](../expansion_simbolica/visual/visual_fase2.png)

## 🧠 Capacidades
- Supervisión diaria automatizada
- Lectura simbólica continua
- Expansión visual y patrimonial
- Respaldo con trazabilidad SHA256
- Publicación ceremonial y técnica

## 📦 Módulos activos
- `supervision_diaria`
- `lecturas_remi`
- `finanzas_remi`
- `expansion_simbolica`
- `respaldo_remi`
- `exportacion_remi`
