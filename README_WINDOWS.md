# Guía de Instalación Rápida - REMI (Windows)

1. Descomprime el paquete del proyecto en una carpeta de tu preferencia (por ejemplo, en el Escritorio o C:\REMI).
2. Haz doble clic en el archivo `.env.example` y cámbiale el nombre a `.env` (puedes abrirlo con el Bloc de notas para configurar tus llaves si es necesario).
3. Haz doble clic en el archivo **`install.bat`**. 
4. El script creará automáticamente el entorno virtual, instalará las librerías limpias y validará el arranque del sistema sin que tengas que configurar comandos complejos en la consola.
