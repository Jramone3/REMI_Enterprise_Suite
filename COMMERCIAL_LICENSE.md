# 🏢 REMI Enterprise Suite — Commercial Model & Licensing

REMI Enterprise Suite operates under an **Open-Core Business Model**.

## 1. Community Edition (Open Source)
* **License:** MIT License (applied to core repository).
* **Target:** Developers, researchers, and small-scale prototypes.
* **Includes:** Core multi-agent framework, basic transaction validators, Streamlit UI, and community support via GitHub Discussions.

## 2. Enterprise Edition (Commercial License)
* **Target:** Mid-to-large enterprises requiring compliance, dedicated support, and advanced security modules.
* **Includes:**
  * Advanced cryptographic compliance packages.
  * Priority bug fixes and 24/7 SLA-backed technical support.
  * Custom smart-contract auditing playbooks and multi-node orchestration tools.
* **Pricing Tiers:**
  * **Team Tier:** Annual subscription per developer seat.
  * **Enterprise / On-Premise Tier:** Flat enterprise license with customized deployment assistance and air-gapped security configurations.

For enterprise inquiries, contact the maintainer directly through the repository channels.
