Agentes de IA que puedes operar, auditar y vender

REMI Enterprise Suite reúne en un solo stack el centro de comando multiagente, un servicio de licencias, pagos con Stripe y on-chain (red Base) y un registro de auditoría en MongoDB.

Todo lo que necesitas para llevar agentes a producción

Centro de comando multiagente

Interfaz Streamlit para operaciones guiadas por IA y chat operativo con el LLM que configures.

Servicio de licencias

API FastAPI para emitir, verificar y consultar licencias por correo, con control de expiración.

Pagos con tarjeta (Stripe)

Webhooks que emiten la licencia automáticamente tras una compra exitosa.

Validación on-chain en Base

Revisa el recibo y los logs de transferencia ERC-20: token, monto mínimo y destinatario.

Auditoría en MongoDB

Licencias y eventos operativos persistidos para trazabilidad y revisión posterior.

Automatización con GitHub

Crea issues técnicos directamente desde la plataforma con un token de bot.

Arquitectura modular

Presentación, backend, verificación de transacciones y persistencia separados en componentes que puedes entender, probar y escalar por separado.

Dockerfile · docker-compose.ymlDespliegue en contenedores

Despliégalo en tu propia infraestructura

Descarga el docker-compose.yml, define tus variables de entorno y levanta el stack.

# 1. Clone / Clonar
git clone https://github.com/Jramone3/REMI_Enterprise_Suite.git
cd REMI_Enterprise_Suite

# 2. Configure env vars / Configurar variables (.env.example)
cp .env.example .env

# 3. Start the stack / Levantar el stack
docker compose up -d
Descargar docker-compose.yml Ver .env.example Checklist de despliegue

Variables obligatorias: MONGO_URI, REMI_DB_NAME, REMI_PAYMENT_ADDRESS, BASE_RPC_URL, REMI_API_KEY, LLM_HOST.
